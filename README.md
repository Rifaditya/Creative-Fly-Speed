# 🚀 Creative Fly Speed (MC 1.20.1)

> "Fly at the speed YOU want."

**Creative Fly Speed** lets you scale Creative and Spectator flight speed via native Minecraft GameRules and dedicated Brigadier commands — no config files, no restarts, instant effect.

**Part of the [Vanilla Outsider](https://github.com/Rifaditya/Creative-Fly-Speed) collection.**

## Features

- **Dynamic GameRules**: `vo_creative_fly_speed:creative_fly_speed` and `vo_creative_fly_speed:spectator_fly_speed`
- **Brigadier Commands**: `/cfs` and `/creativeflyspeed` (`status`, `get`, `set`, `reset`)
- **Instant Sync**: Applied every server tick. No relog required.
- **Server-Side Safe**: Clients don't need the mod installed.
- **Permille Precision**: Integer values — no float config imprecision (1000 = 1.0x).

## Requirements

- **Minecraft**: ~1.20.1
- **Fabric Loader**: >=0.15.11
- **Fabric API**: 0.92.2+1.20.1
- **DasikLibrary**: >=1.4.0
- **Java**: 17+
