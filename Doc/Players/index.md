# Features

**Creative Fly Speed** puts you in control of how fast you fly.

## Feature Pages

- **[Creative Fly Speed](Features/CreativeFlySpeed.md)**: Main feature guide.

## Quick Reference

| Want to... | Command |
| :--- | :--- |
| Double Creative flight speed | `/gamerule creativeFlySpeed 2000` |
| 2.5x Creative flight speed | `/gamerule creativeFlySpeed 2500` |
| Slow Spectator for precision | `/gamerule spectatorFlySpeed 500` |
| Reset both to vanilla | `/gamerule creativeFlySpeed 1000` + `/gamerule spectatorFlySpeed 1000` |

## How To Change Settings

1. **World Creation**: Edit Game Rules → "Creative Fly Speed" category
2. **In-Game (any time)**: `/gamerule <rule> <value>` — takes effect **instantly**, no relog needed.

## Compatibility

- **Server-side only** — clients do not need the mod installed to connect.
- Works alongside any other mod. No known conflicts.
