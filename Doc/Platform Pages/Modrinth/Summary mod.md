# Creative Fly Speed

Adjust Creative and Spectator flight speed via GameRules — no config files, instant effect.

## ✨ Features

- **`creativeFlySpeed`**: Scale Creative mode flight from 0.5x to 10x (or beyond).
- **`spectatorFlySpeed`**: Scale Spectator mode flight independently.
- **Permille Precision**: Use `1000` = 1x, `2500` = 2.5x — exact control without decimals.
- **Instant Sync**: Changes apply live every tick. No relog required.
- **Server-Side Only**: Clients don't need to install the mod.

> **Note**: Uses standard `GameRules`. No config files needed!
